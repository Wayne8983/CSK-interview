## Frontend Task – Community Events UI

### Goal
Build a small UI section that displays community events.

### Requirements
- Use React
- Display 3–5 event cards
- Each card should show:
  - Title
  - Short description
  - Date
  - Action button
- Responsive layout

### Notes
- Data can be hardcoded
- Styling approach is up to you
- Focus on layout, spacing, and clarity
